## What is Zest?

Zest is a fast chess engine designed for the 5x5 mini-chess variant "Gardner minichess."

On the 5x5 board of Gardner chess, it delivers deep search capabilities and high-precision positional evaluation.

Rather than simply searching for the best move, it aims to provide a full-fledged analysis environment equipped with position analysis comparable to Stockfish, as well as Chess.com and Lichess-style move evaluations (such as Brilliant !!, Best ★, and Blunder ??).
